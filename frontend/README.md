# NovaOps Frontend (Vite + React + TS)

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Key files

- `src/pages/HomePage.tsx`: Homepage sections + copy + anchor links
- `src/components/Navbar.tsx`: Sticky navbar (animated on scroll)
- `src/components/motion/*`: Text reveal + scroll-triggered animations
- `src/index.css`: Tokens + Tailwind import + global styles
