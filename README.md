# Tech Startup Portfolio — NovaOps (AI & Automation)

This repo contains the **frontend homepage** for a fictional AI & Automation startup (“NovaOps”): modern UI, responsive layout, and smooth web-style animations.

## Run (Frontend)

```bash
cd frontend
npm install
npm run dev
```

Build:

```bash
cd frontend
npm run build
npm run preview
```

## What’s implemented

- **Responsive homepage (10 sections)**: Hero, Trusted-by, Services, Features, Process, Case Studies, Testimonials, Blog, Newsletter CTA, Contact, Footer
- **Animations**:
  - Loading animation
  - Hero text reveal
  - Scroll-triggered fade-in sections
  - Button hover micro-interactions
  - Sticky navbar (animated + blurred on scroll)
